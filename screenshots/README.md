# Screenshots

This directory will hold AppPortal screenshots, mockups, and future release images.

V0.1 ships a lightweight TUI/mock instead of a full GTK/libadwaita interface. Add screenshots here when AppPortal gains a graphical frontend or when release notes need visual evidence of the current UI state.

Suggested filenames:

- `appportal-home.png`
- `appportal-install-wizard.png`
- `appportal-library.png`
- `appportal-settings.png`
